# Control Arduino with a Phone

> **Status:** Legacy Arduino/Bluetooth experiment. Preserved as a simple embedded-control example.

This project demonstrates sending commands from a phone-based Bluetooth terminal to an Arduino so the microcontroller can react to remote input.

## Concepts demonstrated

- serial communication over a Bluetooth serial module;
- Arduino command handling;
- remote control of low-voltage Arduino outputs;
- use of `SoftwareSerial` where required by the hardware arrangement.

## Scope

This repository is intended as a low-voltage Arduino prototype. Any connected loads or external equipment must remain within the ratings and safety requirements of the components being used.

This is an earlier educational/prototyping project and is not presented as an actively maintained Tech-World product.
